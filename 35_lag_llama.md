# Lag-Llama: лаги как универсальный язык временных рядов

## Ключевая идея

Lag-Llama[^lagllama] — foundation model от ServiceNow/CMU (2024), которая использует **лаговые признаки** как универсальное представление временных рядов. В отличие от Chronos (токенизация) или TimesFM (патчи), Lag-Llama работает с **лагами фиксированных периодов**, что естественно для рядов с сезонностью.

Ключевая инновация — **probabilistic forecasting из коробки**. Модель предсказывает параметры распределения (Student's t), а не точечный прогноз. Это даёт калиброванные prediction intervals без дополнительных методов.

**Результаты:** Lag-Llama показывает конкурентоспособные zero-shot результаты на Monash benchmark, особенно для рядов с выраженной сезонностью[^lagllama].

## Почему лаги?

Лаги (lagged values) — естественный способ представления временных рядов:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    ЛАГИ КАК УНИВЕРСАЛЬНЫЙ ЯЗЫК                          │
│                                                                         │
│  Для прогноза x_t модель получает:                                     │
│                                                                         │
│  x_{t-1}     — значение 1 шаг назад (предыдущее)                       │
│  x_{t-7}     — значение 7 шагов назад (неделя для дневных данных)      │
│  x_{t-14}    — значение 14 шагов назад                                 │
│  x_{t-28}    — значение 28 шагов назад (месяц)                         │
│  x_{t-365}   — значение год назад (годовая сезонность)                 │
│  ...                                                                    │
│                                                                         │
│  Почему это работает:                                                   │
│  ─────────────────────                                                  │
│  1. Сезонность закодирована явно (лаг 7 = недельный паттерн)          │
│  2. Тренд можно вычислить из последовательных лагов                   │
│  3. Не нужно знать абсолютные значения — только относительные         │
│  4. Работает для любой частоты (лаги адаптируются)                    │
│                                                                         │
│  Пример для часовых данных:                                            │
│  • Лаг 1: предыдущий час                                               │
│  • Лаг 24: тот же час вчера                                            │
│  • Лаг 168: тот же час неделю назад                                    │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### Преимущества лагов над другими представлениями

| Представление | Chronos | TimesFM | Lag-Llama |
|---------------|---------|---------|-----------|
| **Подход** | Токенизация | Патчи | Лаги |
| **Сезонность** | Неявная | Неявная | Явная |
| **Потеря информации** | Квантование | Минимальная | Минимальная |
| **Интерпретируемость** | Низкая | Средняя | Высокая |

## Архитектура

Lag-Llama использует **decoder-only transformer** в стиле LLaMA:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        АРХИТЕКТУРА Lag-Llama                            │
│                                                                         │
│  Вход для прогноза x_t:                                                │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  LAG FEATURES                                                   │   │
│  │                                                                  │   │
│  │  [x_{t-1}, x_{t-2}, ..., x_{t-7}, x_{t-14}, x_{t-28}, ...]     │   │
│  │       │        │           │          │          │               │   │
│  │       ▼        ▼           ▼          ▼          ▼               │   │
│  │  Конкатенация в вектор лагов: l_t ∈ ℝ^L                        │   │
│  │  (L = число лагов, обычно 37)                                   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                              │                                          │
│                              ▼                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  INPUT EMBEDDING                                                │   │
│  │                                                                  │   │
│  │  [l_t, time_features_t] → Linear → h_t ∈ ℝ^d                   │   │
│  │                                                                  │   │
│  │  time_features: hour_of_day, day_of_week, month, ...           │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                              │                                          │
│                              ▼                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  LLAMA-STYLE DECODER                                            │   │
│  │                                                                  │   │
│  │  ┌───────────────────────────────────────────────────────────┐ │   │
│  │  │  Layer 1:                                                  │ │   │
│  │  │  • RMSNorm (вместо LayerNorm)                             │ │   │
│  │  │  • Causal Self-Attention с RoPE                           │ │   │
│  │  │  • RMSNorm                                                 │ │   │
│  │  │  • SwiGLU FFN (вместо ReLU)                               │ │   │
│  │  └───────────────────────────────────────────────────────────┘ │   │
│  │  ┌───────────────────────────────────────────────────────────┐ │   │
│  │  │  Layer 2: ...                                              │ │   │
│  │  └───────────────────────────────────────────────────────────┘ │   │
│  │  ...                                                            │   │
│  │  ┌───────────────────────────────────────────────────────────┐ │   │
│  │  │  Layer N: ...                                              │ │   │
│  │  └───────────────────────────────────────────────────────────┘ │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                              │                                          │
│                              ▼                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  DISTRIBUTION HEAD                                              │   │
│  │                                                                  │   │
│  │  h_t → Linear → (μ, σ, ν)                                       │   │
│  │                                                                  │   │
│  │  Параметры Student's t распределения:                          │   │
│  │  • μ: location (среднее)                                        │   │
│  │  • σ: scale (масштаб)                                           │   │
│  │  • ν: degrees of freedom (хвосты)                              │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  Выход: p(x_t | x_{<t}) = Student's t(μ, σ, ν)                        │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### Компоненты архитектуры

**1. RoPE (Rotary Position Embedding)**

Позиционное кодирование из LLaMA. Кодирует относительные позиции через вращение в комплексной плоскости.

$$\text{RoPE}(x, m) = x \cdot e^{im\theta}$$

где $m$ — позиция, $\theta$ — базовая частота.

**2. SwiGLU FFN**

Gated activation function из LLaMA, более эффективная чем ReLU:

$$\text{SwiGLU}(x) = \text{Swish}(xW_1) \odot (xW_2)$$

$$\text{Swish}(x) = x \cdot \sigma(x)$$

**3. RMSNorm**

Упрощённая нормализация без центрирования:

$$\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_{i=1}^d x_i^2}} \cdot \gamma$$

## Лаговые признаки

Lag-Llama использует **фиксированный набор лагов**, адаптированный под частоту данных:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    ЛАГИ ДЛЯ РАЗНЫХ ЧАСТОТ                               │
│                                                                         │
│  Часовые данные (freq='H'):                                            │
│  ──────────────────────────                                             │
│  Короткие: [1, 2, 3, 4, 5, 6, 7]      — последние 7 часов              │
│  Дневные:  [24, 48, 72, 96, 120]     — последние 5 дней (тот же час)  │
│  Недельные: [168, 336, 504]           — последние 3 недели             │
│                                                                         │
│  Дневные данные (freq='D'):                                            │
│  ─────────────────────────                                              │
│  Короткие: [1, 2, 3, 4, 5, 6, 7]      — последняя неделя               │
│  Недельные: [7, 14, 21, 28]           — тот же день недели             │
│  Месячные: [30, 60, 90]               — тот же день месяца             │
│  Годовые: [365, 730]                  — тот же день в прошлом году     │
│                                                                         │
│  Недельные данные (freq='W'):                                          │
│  ─────────────────────────                                              │
│  Короткие: [1, 2, 3, 4]               — последние 4 недели              │
│  Месячные: [4, 8, 12]                 — 1-3 месяца назад               │
│  Годовые: [52, 104]                   — 1-2 года назад                 │
│                                                                         │
│  Всего: 37 лагов (по умолчанию)                                        │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### Обработка пропусков

Если лаг выходит за пределы истории (например, лаг 365 при истории 100 дней), Lag-Llama использует **маскирование**:

```python
# Псевдокод обработки лагов
def get_lag_features(x, t, lags):
    features = []
    mask = []
    for lag in lags:
        if t - lag >= 0:
            features.append(x[t - lag])
            mask.append(1)
        else:
            features.append(0)  # placeholder
            mask.append(0)     # masked
    return features, mask
```

## Student's t распределение

Lag-Llama предсказывает **Student's t распределение** вместо Gaussian:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    STUDENT'S t vs GAUSSIAN                              │
│                                                                         │
│  Gaussian (Normal):                 Student's t:                        │
│  ──────────────────                 ────────────                         │
│       ╱╲                                 ╱╲                              │
│      ╱  ╲                               ╱  ╲                             │
│     ╱    ╲                             ╱    ╲                            │
│    ╱      ╲                           ╱      ╲                           │
│   ╱        ╲                         ╱        ╲ ← тяжёлые хвосты        │
│  ╱──────────╲                       ╱──────────╲                         │
│                                                                         │
│  • Лёгкие хвосты                    • Тяжёлые хвосты                    │
│  • Выбросы маловероятны            • Выбросы более вероятны             │
│  • 2 параметра (μ, σ)              • 3 параметра (μ, σ, ν)             │
│                                                                         │
│  При ν → ∞, Student's t → Gaussian                                     │
│  При малых ν (3-10), хвосты тяжелее                                    │
│                                                                         │
│  Почему Student's t лучше для временных рядов:                         │
│  • Реальные данные часто имеют выбросы                                 │
│  • Student's t робастнее к outliers                                    │
│  • Модель сама учит степень "тяжести" хвостов (ν)                     │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

**Функция плотности:**

$$p(x|\mu, \sigma, \nu) = \frac{\Gamma(\frac{\nu+1}{2})}{\Gamma(\frac{\nu}{2})\sqrt{\nu\pi}\sigma} \left(1 + \frac{1}{\nu}\left(\frac{x-\mu}{\sigma}\right)^2\right)^{-\frac{\nu+1}{2}}$$

**Loss function:**

$$\mathcal{L} = -\sum_{t} \log p(x_t | \mu_t, \sigma_t, \nu_t)$$

## Autoregressive inference

Lag-Llama генерирует прогнозы **авторегрессивно**:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    AUTOREGRESSIVE SAMPLING                              │
│                                                                         │
│  История: [x₁, x₂, ..., xₜ]                                            │
│                                                                         │
│  Шаг 1: Прогноз x_{t+1}                                                │
│  ─────────────────────────                                              │
│  lags = [x_t, x_{t-1}, ..., x_{t-6}, x_{t-23}, ...]                    │
│  (μ, σ, ν) = model(lags)                                               │
│  x̂_{t+1} ~ Student's t(μ, σ, ν)  ← семплируем из распределения        │
│                                                                         │
│  Шаг 2: Прогноз x_{t+2}                                                │
│  ─────────────────────────                                              │
│  lags = [x̂_{t+1}, x_t, ..., x_{t-5}, x_{t-22}, ...]                   │
│           ↑ используем сгенерированное значение                        │
│  (μ, σ, ν) = model(lags)                                               │
│  x̂_{t+2} ~ Student's t(μ, σ, ν)                                       │
│                                                                         │
│  ...продолжаем до горизонта H...                                       │
│                                                                         │
│  Для uncertainty: повторяем N раз (Monte Carlo)                        │
│  forecast_samples: [N, H] — N траекторий длины H                       │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### Базовый пример

```python
from lag_llama.gluon.estimator import LagLlamaEstimator
from gluonts.dataset.pandas import PandasDataset
import pandas as pd

# Подготовка данных
df = pd.DataFrame({
    'target': values,
    'start': pd.Timestamp('2023-01-01')
})

dataset = PandasDataset.from_long_dataframe(
    df, target='target', item_id='id'
)

# Загрузка pretrained модели
estimator = LagLlamaEstimator.from_pretrained(
    "time-series-foundation-models/lag-llama"
)

# Создание predictor
predictor = estimator.create_predictor(
    prediction_length=24,
    context_length=512,
    num_samples=100  # число Monte Carlo samples
)

# Прогноз
forecasts = list(predictor.predict(dataset))

# Каждый forecast содержит:
# - forecast.samples: [num_samples, prediction_length]
# - forecast.mean: point forecast (среднее)
# - forecast.quantile(0.1): 10-й перцентиль
# - forecast.quantile(0.9): 90-й перцентиль
```

### Zero-shot прогноз

```python
import torch
from lag_llama.model import LagLlama

# Загрузка модели
model = LagLlama.from_pretrained("time-series-foundation-models/lag-llama")
model.eval()

# Данные
context = torch.tensor([100, 102, 105, 103, 108, ...]).float()  # история

# Zero-shot прогноз
with torch.no_grad():
    forecast = model.predict(
        context=context,
        prediction_length=24,
        num_samples=100
    )

# Медиана и интервалы
median = forecast.median(dim=0)
p10 = forecast.quantile(0.1, dim=0)
p90 = forecast.quantile(0.9, dim=0)
```

## Сильные стороны

**Компактность.** 7M параметров — можно запускать на CPU, на edge-устройствах, в браузере.

**Probabilistic из коробки.** Student's t распределение с адаптивными хвостами. Калиброванные prediction intervals.

**Лаговое представление.** Естественно для рядов с сезонностью. Явное кодирование периодических паттернов.

**LLaMA-архитектура.** Современные оптимизации (RoPE, SwiGLU, RMSNorm) из NLP.

## Ограничения

**Только univariate.** Нет нативной поддержки multivariate (как в Moirai).

**Autoregressive inference.** Медленнее чем direct prediction (N-BEATS, N-HiTS) для длинных горизонтов.

**Фиксированные лаги.** Набор лагов определён заранее. Для экзотических частот может быть неоптимальным.

**Нет ковариат.** Только history целевой переменной, нет exogenous variables.

## Когда выбирать Lag-Llama

✅ **Используйте Lag-Llama, если:**
- Нужен probabilistic forecast с калиброванными интервалами
- Ограничены вычислительные ресурсы (CPU, edge)
- Данные с выраженной сезонностью
- Важна компактность модели

❌ **Рассмотрите альтернативы, если:**
- Multivariate данные → Moirai
- Нужен point forecast → TimesFM (быстрее)
- Очень длинные горизонты → Chronos (более масштабируем)
- Важны ковариаты → TimeGPT

## Выводы

1. **Лаги как представление** — элегантный подход для рядов с сезонностью. Явное кодирование периодических паттернов.

2. **Student's t** — лучше Gaussian для реальных данных с выбросами. Адаптивные хвосты через параметр ν.

3. **Компактность** — 7M параметров при качестве, сравнимом с моделями в 30-100 раз большего размера. Лучшее соотношение quality/size.

4. **LLaMA-архитектура** — успешный перенос оптимизаций из NLP (RoPE, SwiGLU, RMSNorm).

5. **Практика:** Lag-Llama — отличный выбор для probabilistic forecasting с ограниченными ресурсами.
