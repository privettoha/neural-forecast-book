## N-BEATS

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/privettoha/neural-forecast-book/blob/main/notebooks/11_nbeats.ipynb)

N-BEATS (Neural Basis Expansion Analysis for Interpretable Time Series) — MLP-архитектура, которая строит прогноз через последовательное разложение ряда на компоненты. Показала улучшение на 3% над победителем M4 Competition (ES-RNN) и на 11% над статистическим бенчмарком[^nbeats].

[^nbeats]: Oreshkin, B., et al. "N-BEATS: Neural basis expansion analysis for interpretable time series forecasting." ICLR 2020. Table 11: sMAPE 11.293 vs 11.720 для ES-RNN. https://arxiv.org/abs/1905.10437

### Идея

В основе — **Basis expansion** (разложение по базису). Это не аугментация данных, а способ представить сигнал как комбинацию базисных функций: полиномов для тренда, синусов/косинусов для сезонности.

В generic-режиме модель сама учит удобное представление. В interpretable-режиме базис фиксирован (тренд + сезонность), что делает разложение читаемым.

### Архитектура

```{figure} images/nbeats_architecture.png
:name: fig-nbeats
:width: 80%
:align: center

Архитектура N-BEATS: блоки объединяются в стеки, каждый блок генерирует backcast и forecast
```

Ключевая идея — блоки с двумя выходами:

➖ **Backcast**: часть прошлого, которую блок «объяснил»
➖ **Forecast**: прогноз на заданный горизонт

Резидуальная схема (модель объясняет ряд по частям, каждый раз работая с остатками):

➖ Берём входной контекст
➖ Пропускаем через MLP-блок → получаем параметры $\theta$
➖ Из $\theta$ через базисные функции строим backcast и forecast
➖ Вычитаем backcast из входа → получаем остаток (residual)
➖ Остаток подаём в следующий блок

Модель организована как **стеки блоков**. В interpretable-варианте выделяют отдельные стеки под тренд и сезонность.

### Два режима

| Режим | Базис | Интерпретируемость | Точность |
|-------|-------|-------------------|----------|
| **Interpretable** | Фиксированный (тренд + сезонность) | Высокая | Хорошая |
| **Generic** | Обучаемый | Низкая | Выше |

### Что умеет

➖ Сильный baseline для univariate прогнозирования без экзогенных фичей

➖ Декомпозиция через backcast/forecast: можно анализировать вклад каждого блока — когда прогноз «плывёт», видно, завышает ли модель из-за тренда, сезонности или реакции на всплески (промо), и точечно исправить именно этот компонент

➖ Поэтапно «снимает» структуру ряда — помогает на данных, где смешаны тренды, сезонности и нерегулярные компоненты

### Ограничения

➖ На длинных горизонтах каждая точка предсказывается через полносвязный слой — модель линейно раздувается, прогноз становится нестабильным (N-HiTS решает эту проблему)

➖ Нет нативной поддержки ковариат — для экзогенных переменных нужен N-BEATSx[^nbeatsx]

➖ Фиксированный горизонт при обучении — для другого горизонта нужно переобучать

[^nbeatsx]: Olivares, K., et al. "N-BEATSx: Neural basis expansion analysis with exogenous variables." IJF, 2022. https://arxiv.org/abs/2104.05522

### Когда использовать

**Да:**
➖ Univariate ряды с выраженной структурой (тренд, сезонность)
➖ Короткие и средние горизонты
➖ Нужна интерпретируемость декомпозиции
➖ Достаточно данных для глобальной модели

**Нет:**
➖ Длинные горизонты → N-HiTS
➖ Много ковариат → N-BEATSx, TFT
➖ Cold start → foundation models
➖ Переменный горизонт → рекуррентные модели
