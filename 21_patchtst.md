## PatchTST

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/privettoha/neural-forecast-book/blob/main/notebooks/21_patchtst.ipynb)

PatchTST (Patch Time Series Transformer) делает две ставки: группировать точки в патчи вместо point-wise attention и обрабатывать каналы независимо вместо cross-channel моделирования. Оба решения дают SOTA на стандартных бенчмарках[^patchtst].

[^patchtst]: Nie, Y., et al. "A Time Series is Worth 64 Words: Long-term Forecasting with Transformers." ICLR 2023. https://arxiv.org/abs/2211.14730

### Идея: почему патчи

Одна точка ряда — просто число без контекста. Значение 150 может означать что угодно: пик сезона, случайный выброс, норму. Point-wise attention сравнивает эти голые числа — точка 150 похожа на точку 148, даже если одна на пике, другая в провале.

Патч из 16 точек — это уже кусок ряда с локальным паттерном: тренд, волатильность, форма. Трансформер сравнивает паттерны, а не числа.

### Механика патчинга

Ряд длины $L = 96$, размер патча $P = 16$, шаг $S = 8$:

```
Патч 1: точки 0–15
Патч 2: точки 8–23
Патч 3: точки 16–31
...
```

Количество патчей: $N = \lfloor (L - P) / S \rfloor + 1 = 11$

Каждый патч проецируется в пространство размерности $D$:

$$z_i = W \cdot \text{patch}_i + b, \quad W \in \mathbb{R}^{D \times P}$$

Добавляется positional encoding → последовательность из $N$ токенов → стандартный transformer encoder.

### Почему патчинг работает

➖ **Богатая семантика**: патч содержит локальный тренд, волатильность, форму — осмысленная единица для сравнения

➖ **Снижение сложности**: $L = 512$ с $S = 8$ даёт ~64 токена вместо 512. Сложность attention падает с $512^2$ до $64^2$ — в 64 раза

➖ **Длинный контекст**: при фиксированном бюджете можно смотреть на более длинную историю

➖ **Локальная инвариантность**: небольшие сдвиги не меняют патч радикально — встроенная аугментация

### Channel independence

Вторая идея — обрабатывать каналы независимо. Вход $(B, C, L)$ преобразуется в $(B \cdot C, L)$, обрабатывается как набор одномерных рядов, результат собирается обратно.

Контринтуитивно: теряем зависимости между каналами. Но на практике работает:

➖ **Меньше параметров**: cross-channel модель учит $C^2$ взаимодействий, многие из которых слабые или отсутствуют

➖ **Лучшая генерализация**: модель применима к другому набору каналов — важно для transfer learning

➖ **Достаточность локальной информации**: для многих задач история самого ряда достаточна для прогноза

➖ **Эмпирика**: авторы сравнили варианты — channel independence побеждает на большинстве датасетов

### Архитектура

```
Input x ∈ ℝ^L
    ↓ Instance Normalization
    ↓ Patching: N патчей размера P с шагом S
    ↓ Patch Embedding: линейная проекция в ℝ^D
    ↓ + Positional Encoding
    ↓ Transformer Encoder (стандартный)
    ↓ Flatten + Linear → прогноз длины H
Output ŷ ∈ ℝ^H
```

**Instance Normalization**: вычитается среднее, делится на std — модель инвариантна к масштабу. После прогноза — обратное преобразование.

**Transformer Encoder**: стандартный из «Attention Is All You Need»[^attention] — multi-head self-attention, FFN, residuals, LayerNorm. Никаких модификаций для рядов — вся адаптация через патчинг.

[^attention]: Vaswani, A., et al. "Attention Is All You Need." NeurIPS 2017. https://arxiv.org/abs/1706.03762

### Self-supervised pretraining

Идея из BERT[^bert]: маскируем случайные ~40% патчей, обучаем модель их восстанавливать (MSE loss).

[^bert]: Devlin, J., et al. "BERT: Pre-training of Deep Bidirectional Transformers." NAACL 2019. https://arxiv.org/abs/1810.04805

Полезно когда:
➖ Много исторических данных, мало размеченных примеров
➖ Нужен transfer на новый домен
➖ Хочется универсальное представление для разных задач

### Что умеет

➖ Эффективен на длинных входах и горизонтах (ETTh1, горизонт 720 — значительно лучше конкурентов)

➖ Простая архитектура: стандартный transformer + патчинг, без сложных механизмов

➖ Transfer learning через pretraining и channel independence

➖ SOTA на long-term forecasting бенчмарках (на момент публикации 2023)

### Ограничения

➖ **Гиперпараметры патчинга**: размер $P$ и шаг $S$ нужно подбирать под данные — для часовых данных с суточной сезонностью патч 24 имеет смысл, для других — нет

➖ **Потеря fine-grained информации**: патчинг агрегирует — если важны точные значения в конкретные моменты (пик в 18:00), информация может размыться

➖ **Channel independence как ограничение**: для данных с сильными межканальными зависимостями (взаимодополняющие товары) → TSMixer или iTransformer

➖ **Вычислительная стоимость**: трансформер тяжелее MLP-моделей — проблема для real-time или edge

### Когда использовать

**Да:**
➖ Длинные входные последовательности (сотни точек)
➖ Достаточно вычислительных ресурсов
➖ Важен transfer learning / pretraining
➖ Каналы относительно независимы

**Нет:**
➖ Сильные межканальные зависимости → TSMixer, iTransformer
➖ Простые задачи с коротким горизонтом → N-HiTS
➖ Real-time / edge inference → MLP-модели
➖ Ограниченные ресурсы

### PatchTST vs другие

| Критерий | PatchTST | N-HiTS | TSMixer |
|----------|----------|--------|---------|
| Длинные входы | ✓ | ✓ | ~ |
| Длинные горизонты | ✓ | ✓✓ | ✓ |

| Transfer learning | ✓✓ | ~ | ~ |
